# Toolbar icons

Source: Hugeicons Pro 4.3.4 (`@hugeicons-pro/core-stroke-rounded` and `@hugeicons-pro/core-solid-rounded`).

All inline capture toolbar icons, main bar, secondary properties bar, long screenshot bar, and recording bars are generated by `scripts/generate-toolbar-icons.py` into `Snapzy/Resources/Assets.xcassets/CaptureTool-*.imageset`.
The mapping from toolbar slot to Hugeicons name lives in that script. Style: Stroke Rounded with stroke width `1.8` on the `24`-unit grid (`1.5 pt` at `20 pt`); a selected tool or option switches to the Solid Rounded variant (`CaptureTool-<key>-fill`). Rectangle, oval, filled rectangle, arrow display types and endpoint shapes keep one look in every state because their fill carries meaning.

Key icon groups:
- **Main toolbar tools & actions**: `selection` (`Cursor01`), `rectangle` (`RectangleHorizontal`), `filledRectangle`, `oval` (`Circle`), `arrow` (`ArrowUpRight03`), `line` (`Slash`), `pencil` (`PencilEdit01`), `highlighter` (`Highlighter`), `text` (`Text`), `blur` (`Grid3x3`), `spotlight` (`Spotlight`), `counter` (`OneCircle`), `watermark` (`Copyright`), `undo` (`Undo03`), `redo` (`Redo03`), `scrolling` (`CarouselVertical`), `crop` (`Crop`), `record` (`Video01`), `copy` (`Copy01`), `pin` (`Pin`), `save` (`Download04`), `cancel` (`Cancel01`), `more` (`MoreHorizontal`).
- **Recording prep, active & playback bars**: `rec-back` (`ArrowLeft02`), `rec-audio-on` / `rec-audio-off` (`VolumeHigh` / `VolumeOff`), `rec-mic-on` / `rec-mic-off` (`Mic01` / `MicOff01`), `rec-pause` (`Pause`), `rec-play` (`Play`), `rec-stop` (`StopCircle` Solid Rounded), `rec-redo` (`ArrowReloadHorizontal`).

The standalone Annotate window still uses SF Symbols.
