# Toolbar icons

Source: Hugeicons Pro 4.3.4 (`@hugeicons-pro/core-stroke-rounded` and `@hugeicons-pro/core-solid-rounded`).

All inline capture toolbar icons, main bar and properties bar, are generated by
`scripts/generate-toolbar-icons.py` into `Resources/Assets.xcassets/CaptureTool-*.imageset`.
The mapping from toolbar slot to Hugeicons name lives in that script. Style: Stroke Rounded with
stroke width 1.8 on the 24-unit grid (1.5pt at 20pt); a selected tool or option switches to the Solid
Rounded variant (`CaptureTool-<key>-fill`). Rectangle, oval, filled rectangle, arrow display types and
endpoint shapes keep one look in every state because their fill carries meaning.

The full Annotate window still uses SF Symbols.
